# esi-shopping-list

This was from awhile ago so I don't remember exactly what I was doing. The code is a mess, but it does somewhat work.

`fetch.py` will actually fetch your assets and put them into various json files named based on the character id you logged into esi with.

`dupes.js` will compare all items to figure out which ones are the same. This prevents the main script from complaining about "oh you have a Republic Fleet Warp Scrambler equipped but you need to swap it for a True Sansha Warp Scrambler."

`main.js` does the real work. It has a few prereqs:
1. `sqlite-latest.sqlite` exists. I think I got this from fuzzworks. It's way easier dealing with this than actual ESI shit or the `.jsonl` for static data, but probably want to switch away from this.
2. `savedata.db` exists. This is the pyfa db from the alliance pyfa bat script.
3. `dupes.json` exists. This should be generated by running `dupes.js`, but that outputs to stdout, so you need to save it to a file.
4. `my-diffs.json` exists. This is a json file that describes how fits should actually differ from the `savedata.db` database fits. I don't think I was ever happy with this format. This should be entirely revisited.

Here's an example from my `my-diffs.json` file:
```
[
  {
    "fitName": "Armor Archon",
    "checks": [
      {
        "typeName": "Mobile Depot",
        "quantity": 0,
        "location": "cargo"
      }
    ],
    "adds": [
      {
        "typeName": "Mobile Depot",
        "quantity": 1,
        "location": "cargo"
      }
    ]
  },
]
```
The `fitName` has to match the fit in the pyfa database. I want to make sure I have a Mobile Depot in the cargo, but the fit doesn't specify. I don't know why this is in both "checks" and "adds".

There is no way to figure out what charges are loaded in a ship unless you are sitting in that ship in game. This is frustrating.

The main script only cares about modules as a whole. It doesn't try to separate high slots from low slots, because there are no modules that can go in both, so you don't really care where it is, only that it's fit. Likewise for SubSystemBay / Cargo / FleetHangar / SpecializedFuelBay, and for FighterBay / FighterTube. Frigate escape bays are also checked but I remember not being happy about how I approached this.
